# 03 红线速查：批了也没用，别往审批里塞

**结论**：下面七条都是企微平台当前的固定行为，**审批无法解锁**——审批时对照这张表，属于红线的诉求直接转技术方案，别塞进审批流程空转。

| 红线 | 怎么绕 |
| :--- | :--- |
| ① 机器人写不了别人建的表（把表"共享"给机器人也不行，实测过） | 机器人建新表记新数据，旧表挂索引 |
| ② 读别人的表要授权+发链接 | 提前做好[[02-提审/02-授权三步-建号扫码发链接\|授权三步]]的第二步、第三步 |
| ③ 智能表格最多单独授权 20 人 | 按群/全员设置，或拆表 |
| ④ 智能表格权限只有三档（可看/可改/可管理） | 敏感数据拆表 |
| ⑤ 机器人只有建它的人能用 | 一人一个机器人，各自申请 |
| ⑥ "下载-上传"改表会覆盖别人刚改的内容 | 多人共用的表禁用此方式；机器人改过的格子加底色 |
| ⑦ 机器人自建的表，界面上没有"设管理者"的入口 | 同事要能改：开"企业内自助加入"；要"管理者"：找企微超管兜底，别当配置问题排查 |

**给技术实施同事的三条提醒**（智能表格既定行为，不是 bug）：新建智能表格自带的默认字段必须先改名再新增字段；写入时用字段标题做列名、不是字段 ID；单次写入建议 500 行以内。

**前车之鉴**：DDD 曾把"写旧表"当审批问题推给组织发展部门，批完依然写不进。记住分工——**审批只解决"读"的授权；"写"的诉求直接转架构方案**（机器人建新表）。
