# 01 上线检查清单：逐项打勾才可上线

**结论**：机器人上线前，拿这张清单逐项打勾——**任何一项打不上勾，就不予上线**。勾完再走[[03-登记/02-登记台账-在线表格|台账登记]]。

- [ ] 要动的表都定过级，没有敏感、绝密数据违规（分级标准见 [[01-提议-组织SOP|组织SOP提议]]）
- [ ] 机器人只往自己建的表写，不碰员工旧表
- [ ] 多人共用的表没有用"下载-上传"方式改
- [ ] 新旧表哪个算数、什么时候切换，白纸黑字定了
- [ ] 机器人只对实际使用的群和同事开放
- [ ] 文档管理员只有机器人和搭建者本人，没有把文档管理员再授权给别人（同事编辑走"企业内自助加入"，管理兜底找超管）
- [ ] 台账登记完成（含负责人与交接人），代码脚本已存公司 GitHub 私有仓库
