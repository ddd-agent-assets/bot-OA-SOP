# 02 创建机器人：只有管理员能建，业务同事建不了

**结论**：企微机器人**必须由管理员（DIC IT，企微超级管理员，目前就几个人）创建**，业务同事在后台没有创建入口——想搭机器人，第一步永远是找管理员建号。建好后管理员配置"谁能用"、逐项打开权限开关，你拿到机器人才能开始用。

## 一、在哪建、怎么建（管理员操作）

- **入口**：企业微信后台 → 工作台 → 智能机器人 → 手动创建 → **API 模式 → 长连接**；
- **不需要公网服务器**，公司内网环境也能跑（给 IT 的一句话：接入走官方工具 `@wecom/cli` 或 MCP 通道，前提是 Node.js 环境 + 长连接机器人的 Bot ID 和 Secret）；
- 建好后管理员会拿到 **Bot ID + Secret**（机器人的"账号密码"），需妥善保存，泄露=任何人都能以机器人身份操作。

## 二、建完还要配两件事

| 要配的事 | 说明 |
| :--- | :--- |
| **可用范围** | 配置哪些群、哪些同事能用这个机器人——只开给实际使用的人，别全员开放 |
| **逐项开权限** | 默认权限最小化、一项一个独立开关，用到哪项开哪项——完整的 12 类权限清单见下面第三节 |

## 三、机器人能开哪些权限（官方 12 类，默认全关、逐项开）

机器人默认权限**最小化**，能力是**一项一项的独立开关**——"能读文档"和"能查通讯录"就是两个开关，**用到哪项开哪项，别开全家桶**。报错提示里通常自带"去开通"链接，要让**创建机器人的那个人**点开才有效。

按官方工具的能力清单，机器人权限共 12 类（[官方清单](https://github.com/WecomTeam/wecom-cli)）：

| 权限 | 开了能干什么 | 典型场景 |
| :--- | :--- | :--- |
| 消息 | 向聊过的群/单聊主动推送通知 | 异常告警、日报 |
| 文档 | 新建、读取、追加、覆盖写文档 | 报告生成、信息汇集 |
| 文档管理 | 搜索各类文档；文档/表格重命名、成员权限与加入规则管理 | 找文档、管自建表 |
| 在线表格 | 新建、导入、读改、追加行 | 台账登记 |
| 智能表格 | 建表、子表/字段/记录/视图管理 | 数据库型台账 |
| 智能文档 | 创建、读取、编辑智能文档 | 带数据表的文档 |
| 微盘 | 搜索、上传、下载企业网盘文件 | 资料归档 |
| 邮件 | 发送/回复/转发/检索、读正文 | 客户来信汇总 |
| 待办 | 创建/分派/完成待办 | 任务提醒 |
| 日程 | 增删改查、查闲忙、订会议室 | 行政助手 |
| 会议 | 预约/取消、读会议纪要与转写 | 自动纪要 |
| 通讯录 | 按姓名/拼音搜同事、查成员信息 | @人、多人协作 |

注：官方按"能力品类"公布清单，后台开关的粒度以实际配置页为准；实测确认至少"文档"和"通讯录"是相互独立的开关。

## 四、建好之后干什么

机器人建好只是"出生"，还不能用——接下来要走**发布审批和授权**，见 [[02-提审/01-发布先过两轮审批-上级加管理员|提审篇：发布先过两轮审批]]。
