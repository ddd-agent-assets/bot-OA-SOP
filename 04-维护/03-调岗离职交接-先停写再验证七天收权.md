# 03 调岗离职交接：先停写、再验证、七天后收权

**结论**：搭机器人的同事调岗或离职，按这四步交接——**先停写、再双人验证、重新授权、七天后收权**。前提是[[03-登记/02-登记台账-在线表格|台账]]登记完整，没台账就没有交接。

1. 台账里该同事名下的机器人、表格、脚本先**停写**（保留查看）；
2. 交接双方一起验证：机器人能用吗、表权限对吗、定时任务在跑吗、积分账号还剩多少、GitHub 仓库能打开吗（公司仓库在 [ddd-agent-assets](https://github.com/ddd-agent-assets)，权限找 Rosetta 或 Yomi 调整）；
3. 换负责人要**重新扫码授权 + 重发文档链接**（平台规矩：权限不跟着人走，见 [[02-提审/04-必须走的流程-企微强制没有商量|必须走的流程]]）；
4. 台账更新，**7 天后**收回原负责人权限。
